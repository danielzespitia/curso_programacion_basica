1

Mi Primera Página Web

Estructura básica de HTML
🎯 Objetivo: Familiarizarse con la estructura básica de un archivo HTML y el uso de las etiquetas más fundamentales.

📋 Requisitos

  • Crear un nuevo archivo llamado ejercicio1.html.
  • Escribir la estructura HTML completa: <!DOCTYPE html>, <html>, <head>, <body>.
  • Dentro del <head>, añadir <title> que diga "Mi Primer Ejercicio".
  • Dentro del <body>, añadir <h1> que diga "Hola, Mundo!".
  • Debajo del <h1>, añadir <p> que diga "Estoy aprendiendo HTML y es increíble."
  • Abrir el archivo en el navegador para ver el resultado.
2

Listas y Enlaces

Hipervínculos y listas
🎯 Objetivo: Practicar la creación de listas y cómo convertir texto en hipervínculos.

📋 Requisitos

  • Crear un nuevo archivo ejercicio2.html.
  • Añadir <h2> que diga "Mis Sitios Web Favoritos".
  • Crear una lista desordenada <ul> con tres <li>.
  • Cada elemento debe tener un enlace <a> a un sitio diferente (Google, YouTube, Wikipedia).
✨ Extra Opcional

Añade una segunda lista ordenada <ol> con los pasos que sigues para estudiar.

3

Agregando una Imagen

Insertar imágenes
🎯 Objetivo: Aprender a insertar imágenes locales y externas en una página.

📋 Requisitos

  • Crear un archivo ejercicio3.html.
  • Añadir un <h1> que diga "Mi Animal Favorito".
  • Buscar una imagen de tu animal favorito en internet.
  • Insertar la imagen con <img src="URL" alt="descripción">.
  • Añadir un texto alternativo descriptivo en el atributo alt.
✨ Extra Opcional

Debajo de la imagen, añade un <p> que dé crédito a la fuente con un enlace.

4

Mi Primera Hoja de Estilos

Vincular CSS externo
🎯 Objetivo: Conectar por primera vez un archivo CSS a un HTML y aplicar estilos básicos.

📋 Requisitos

  • Crear ejercicio4.html y estilo4.css.
  • En el HTML: estructura básica con <h1> y dos párrafos <p>.
  • Enlazar la hoja de estilos desde el <head> con <link>.
  • En el CSS — body: background-color: #f0f0f0
  • En el CSS — h1: color: navy
  • En el CSS — p: font-size: 18px
5

Usando Clases y IDs

Selectores CSS
🎯 Objetivo: Entender la diferencia entre estilos generales, clases e IDs.

📋 Requisitos

  • Crear ejercicio5.html y estilo5.css.
  • En el HTML: un <h1> y tres párrafos.
  • Al primer párrafo: class="destacado".
  • Al tercer párrafo: id="resumen".
  • CSS — .destacado: background: yellow + font-weight: bold
  • CSS — #resumen: font-style: italic + color diferente
6

El Modelo de Caja (Box Model)

padding · border · margin
🎯 Objetivo: Practicar con padding, border y margin.

📋 Requisitos

  • Crear ejercicio6.html y estilo6.css.
  • En el HTML: <div class="caja"> con un <h2> y un <p>.
  • CSS — .caja: width: 400px
  • background-color: #eaf2f8
  • border: 2px solid #3498db
  • padding: 20px  +  margin: 30px
7

Tarjeta de Presentación Simple

Componente visual
🎯 Objetivo: Combinar HTML y CSS para crear un componente visual común.

📋 Requisitos

  • Crear ejercicio7.html y estilo7.css.
  • HTML: <div class="tarjeta"> con: <img>, <h2> (nombre), <p> (cargo).
  • Puedes usar https://via.placeholder.com/150 como imagen de prueba.
  • CSS .tarjeta: borde, color de fondo, box-shadow, ancho fijo y border-radius.
  • Contenido centrado con text-align: center.
✨ Extra Opcional

Haz la imagen de perfil redonda: border-radius: 50%.

8

Estructura Semántica

HTML5 semántico
🎯 Objetivo: Utilizar etiquetas semánticas para estructurar una página correctamente.

📋 Requisitos

  • Crear ejercicio8.html y estilo8.css.
  • <header> con <h1> que diga "Mi Blog".
  • <main> con un párrafo de contenido.
  • <footer> con <p> "Copyright © 2025".
  • CSS: dar un color de fondo diferente a cada sección semántica.
9

Menú de Navegación Estilizado

Navbar horizontal
🎯 Objetivo: Estilizar una lista como menú de navegación horizontal.

📋 Requisitos

  • Crear ejercicio9.html y estilo9.css.
  • HTML: <nav> con <ul> y 4 <li>, cada uno con un <a>.
  • CSS — quitar viñetas y padding del <ul>.
  • CSS — <li>: display: inline-block.
  • CSS — <a>: text-decoration: none + padding + background-color.
✨ Extra Opcional

Añade efecto :hover en los enlaces del menú.

Proyecto Final – Mini Página Biográfica

Consolidar todos los conocimientos
🎯 Objetivo: Consolidar todos los conocimientos de HTML y CSS en una sola página completa y bien estilizada.

📋 Requisitos

  • Crear biografia.html y estilo-bio.css.
  • <header> con tu nombre en <h1>.
  • <main> con una <section> "Sobre Mí" (foto incluida) y otra <section> "Mis Hobbies" (lista <ul>).
  • <footer> con tus redes sociales (enlaces de texto).
  • Usa CSS para estilizar toda la página: colores, fuentes, márgenes y clases.
